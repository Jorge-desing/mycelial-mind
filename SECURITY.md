## Reportar una vulnerabilidad

Si detectas una vulnerabilidad (por ejemplo, escalada de permisos en comandos/red, denegación de servicio en servidor, exposición de credenciales o problemas en workflows/scripts):

1. **No** abras un issue público con detalles explotables.
2. Usa **Private vulnerability reporting** en la pestaña **Security** del repositorio de GitHub (o contacta directamente al mantenedor `@Jorge-desing`).
3. Incluye versión del mod, pasos mínimos de reproducción y el impacto observado.
