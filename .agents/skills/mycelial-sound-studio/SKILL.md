# Estudio Procedural de Audio y Motor OpenAL EFX v7 — Minecraft Foley Craft (`scripts/sound_studio/` + `client/audio/`)

Genera, mezcla y audita acústicamente todos los efectos propios (`mycelialmind:*`) en **Ogg Vorbis mono `44100 Hz` (`ffmpeg -c:a libvorbis -q:a 4`)** usando 5 motores de síntesis orgánica/física multicapa en `numpy` + `scipy.signal` + CUDA bajo estética **Deep Dark / Sculk + relojería de cobre/amatista/redstone** (100% original, cero redirecciones vanilla), y aplica acústica espacial nativa **OpenAL EFX en vivo** con humanización anti-repetición **+ modelado de timbre HF (`timbreDamping`)** (sin Mixins ni ATs) en tiempo real.

## 2. Invariantes Obligatorios y Motor Runtime Java (v7)
1. **Mono `44100 Hz` estricto (`channels == 1`):** `build_sounds.py --check` verifica la cabecera Vorbis ID de los `596` `.ogg` y purga huérfanos. Conversión atómica por pipe PCM16→`ffmpeg -c:a libvorbis -q:a 4 -ac 1 -ar 44100 -f ogg`.
2. **Límites Acústicos y Cero Sonidos Vanilla:** `true_peak_dbfs <= -0.25`, `peak_dbfs <= -0.25`, `|dc_offset| <= 0.01`, bordes `< 0.02`, `loop_seam_delta <= 0.025` en los **11 `SEAMLESS_LOOP_IDS`**, desviación `<= ±3.0 dB`, correlación `< 0.85` (objetivo `< 0.55`), `psychoacoustic_masking.ok == True` y `stem_qc_summary.ok == True`. Prohibido `"type": "event"` en `sounds.json` y **cero `SoundEvents.*` / `SoundType.*`** en `src/main/java/`.

## 3. Flujo Recomendado
La validación `--check` decodifica todos los Ogg a flotante antes de medir el pico verdadero 4x y los cuatro samples de cada borde: el Vorbis puede introducir picos o pre-eco que no existen en el PCM previo. La codificación reintenta desde el PCM original con margen y, para one-shots, un fundido adaptativo si el borde decodificado es excesivo; no aplica dicho fundido a los bucles. En regeneraciones filtradas, las métricas detalladas de eventos reutilizados pueden proceder de un manifiesto anterior: no confundirlas con el barrido de picos y bordes de los archivos actuales.
1. **Vía FastMCP `CodeMode` (`mycelial-mind-dev`):**
   - `await call_tool("run_sound_studio", {"check_only": False, "changed_only": True, "check_baseline": True, "run_tests": True})`
   - `await call_tool("audit_sound_masking", {"top_n": 12})` (Bark 24-bandas, `mean_organic_index`, `bark_unmasking_applied`, LRA, diversidad y QC de 95 stems) e `inspect_sound_event(sound_id=...)`.
   - `await call_tool("audit_mod_assets", {})` (`sounds_json_count == 226`, `ogg_files_count == 596`, `missing_sound_files == []`, `vanilla_event_redirects == 0`, `audio_quality_ok == True`).
2. **Previsualización humana local:** abrir `scripts/sound_studio/exports/sound_audition.html` (Consola WebAudio v7 con `Org μ`, simulador OpenAL EFX/inmersión, crossfader de camas adaptativas y matriz Bark).
3. **Fallback por CLI:** `python scripts/sound_studio/build_sounds.py --all --update-baseline --check` (o `--changed-only --check-baseline`) y `python -m unittest scripts/sound_studio/tests/test_sound_studio.py -v` (GPU y `CUDA_VISIBLE_DEVICES=-1`).
